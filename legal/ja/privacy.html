1. AliKa について

AliKa は、保護者がお子さまの端末の利用時間を管理するための、隠れずに動作するペアレンタルコントロールアプリです。アプリは端末上に表示され、ロック画面や通知もお子さまに見える形で表示されます。

AliKa は、端末の所有者または保護者が、お子さまに知らせたうえでインストールしてください。本人の同意なく他人の端末でひそかに使うことは禁止しています。

Android 版は、Google Play にペアレンタルコントロール（見守り）ツールとして申告しています。アイコンは隠れず、保護中は常時通知が表示されます。Google Play プロテクトが、見守りアプリがインストールされていることを端末の利用者に知らせる場合があります。

次のデータは、保護者の管理機能のために端末内（ローカル）でのみ扱います。

データ目的
使用したアプリの名前と利用時間利用レポート、時間制限
閲覧した Web サイト・動画のタイトルとアドレス保護者による確認、フィルタリング
ロック・制限・ブロックのイベントイベント履歴

これらのデータは端末内、または保護者が許可した家庭内ネットワーク上で、ペアリングした家族の端末間を暗号化して直接やり取りします。AliKa が運営するクラウドは経由しません。

3. AliKa のサーバーに送られるもの

お子さまの利用履歴、プロフィール、学習内容、メッセージ、閲覧したドメイン、位置情報は、AliKa のサーバーに送りません。サーバーに送られるのは次の場合だけです。

  • Android ファミリーサブスクリプションの確認：1つのサブスクリプションを最大10台で使うために、ランダムな家族 ID と端末 ID、端末公開鍵の SHA-256 ハッシュ、端末の役割、失効状態、Google Play の商品・購読状態・支払い済み期間の終了日時を扱います。購入トークンは SHA-256 ハッシュとしてのみ保存します。Google アカウント名やメールアドレスは扱いません。利用されていない、または期限切れの家族の記録は90日以内に削除します。
  • 無料アクセスコード（任意）：保護者がコードを入力した場合だけ送信します。Windows ではコードと、この PC から計算した一方向の識別子（Windows のマシン ID の SHA-256 ハッシュ。マシン ID そのものは送りません）を送ります。サーバーにはコードのハッシュ、最初に結び付いた端末の識別子、無料期間の開始日と終了日だけを保存します。コードの再利用を防ぐため、この記録は90日の削除の対象外です。削除をご希望の場合は destek@alika.tr までご連絡ください。

通信は HTTPS/TLS で暗号化します。Google Play での購入は、Google のプライバシー規約に基づいて Google が扱います。

4. 保護者が送る問題の報告

保護者パネルの「問題を報告」ボタンを押すと、端末内で ZIP ファイルが作られ、保護者ご自身のメールアプリで destek@alika.tr 宛ての下書きが開きます。自動で送られることはありません。保護者がメールを送った場合だけ、ErenKa Software に届きます。

報告には過去7日分の端末・システム情報、AliKa のバージョンと設定、権限の状態、クラッシュの記録、イベント履歴、アプリごとの利用時間が含まれます。PIN とそのハッシュ、パスワード、トークン、お子さまの名前、閲覧履歴、家族のメッセージ、録音、写真、位置情報、連絡先は含まれません。メールの送信者アドレスと本文は ErenKa Software に届きます。

問題のある問題（誤った正解など）を報告する「報告」ボタンも同じ扱いです。報告には問題とパックの識別子、問題文と選択肢、入力された説明（500文字まで）だけが含まれ、お子さまの名前や解答は含まれません。

報告は AliKa の問題を見つけて直し、保護者に返信するためだけに使い、受け取ってから12か月以内に削除します。早めの削除も destek@alika.tr で受け付けます。

7. Web サイト（www.alika.tr）

この節は Web サイトだけに当てはまり、アプリには当てはまりません。アクセス数を数えるために Cloudflare Web Analytics を使っています。Cloudflare によると、このサービスは指標の収集に Cookie やローカルストレージを使わず、IP アドレスなどによる閲覧者の識別も行いません。ErenKa Software が見るのは、ページビュー数、参照元、国、端末の種類などの集計値だけです。

8. 開示・訂正・削除などのご請求

  • 端末内のデータ：保護者パネルで確認でき、履歴や取り込んだ教材は保護者パネルから削除できます。AliKa をアンインストールすると、Android ではアプリのデータが削除されます。Windows では再インストールに備えて %ProgramData%\AliKa\ と %LocalAppData%\AliKa\ が残るため、すべて消すにはアンインストール後にこの2つのフォルダーを削除してください。
  • サーバーの記録（Android）：件名を「AliKa Android data deletion request」として destek@alika.tr にメールし、アプリのサブスクリプション画面に表示される家族 ID と端末 ID をお知らせください。他人による削除を防ぐため、端末での確認をお願いする場合があります。お子さまの名前、PIN、購入トークンは送らないでください。
  • 問題の報告：報告を送ったアドレスから destek@alika.tr に削除をご依頼ください。
  • 保有する個人データの利用目的の通知、開示、訂正、利用停止、削除などのご請求や、取り扱いに関するご相談も destek@alika.tr で受け付けます。日本語でも英語でもご連絡いただけます。

9. 安全管理

端末内の設定は保護者 PIN で守られ、PIN は PBKDF2-HMAC-SHA256 でハッシュ化して保存します。サーバーとの通信は HTTPS/TLS、端末の公開鍵、ハッシュ化したトークンを使い、本番の記録にアクセスできるのは確認と削除に必要なサービスだけです。端末自体の安全（ディスクの暗号化や OS の更新）は利用者の責任となります。
